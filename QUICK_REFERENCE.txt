## Start the Application

### Terminal 1 - Backend
```bash
cd backend
mvn spring-boot:run
```

Backend runs on: http://localhost:8080

### Terminal 2 - Frontend
```bash
cd frontend/nanourl-frontend
npm run dev
```

Frontend runs on: http://localhost:5173
