## **🚀 Quick Commands**

### **Database Setup**
```bash
mysql -u root -p < database/database_schema.sql
```

### **Start Backend**
```bash
cd backend
mvnw spring-boot:run
```

### **Start Frontend**
```bash
cd frontend/nanourl-frontend
npm run dev
```

### **View Data**
```bash
mysql -u nanourl_user -p nanourl_db
SELECT * FROM users;
```
