# 🚀 NanoURL - Quick Reference Guide

## ⚡ 30-Second Setup

### 1. Ensure MySQL Running
```bash
mysql -u root -p
CREATE DATABASE nanourl_db;
EXIT;
```

### 2. Start Backend (Terminal 1)
```bash
cd backend
mvnw.cmd spring-boot:run
```

### 3. Start Frontend (Terminal 2)
```bash
cd frontend/nanourl-frontend
npm install
npm run dev
```

### 4. Open Browser
```
http://localhost:5173
```

✅ **Done!** You have a fully functional URL shortener

## 🔗 API Endpoints

```
POST   /api/auth/signup          - Create account
POST   /api/auth/signin          - Login
GET    /api/auth/verify          - Verify token
GET    /api/auth/me              - Get user info

POST   /api/shorten              - Create short URL
GET    /api/{code}               - Redirect to original
GET    /api/urls/history         - Get user's URLs
DELETE /api/urls/{id}            - Delete URL
```

## 🐛 Troubleshooting

| Problem | Solution |
|---------|----------|
| MySQL won't connect | Check MySQL running: `mysql -u root -p` |
| Port 8080 in use | Change in `application.yaml` |
| Port 5173 in use | Change in `vite.config.js` |
| npm not found | Install Node.js |
| Java not found | Install Java 21 JDK |
